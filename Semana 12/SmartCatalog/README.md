# SmartCatalog — Programación en Móviles

Proyecto Android desarrollado durante el curso de Programación en Móviles, utilizando Kotlin, Jetpack Compose y arquitectura MVVM.

La aplicación permite consultar un catálogo de celulares, gestionar favoritos y acceder a funcionalidades según el rol del usuario.

## Rama de mejoras con inteligencia artificial

Como parte del proyecto, se creó una rama independiente denominada **`mejora-ia-smart`**, donde se implementaron nuevas funcionalidades y mejoras visuales con apoyo de inteligencia artificial.

### Acceder a la versión mejorada

**[Ver SmartCatalog 2.0 — Rama mejora-ia-smart](https://github.com/RamsesAlvrz/Programacion-en-Moviles/tree/mejora-ia-smart/Semana%2012/SmartCatalog)**

## Mejoras implementadas

| N.º | Mejora | Descripción |
|---|---|---|
| 1 | Catálogo interactivo | Búsqueda, filtros por marca y ordenamiento de celulares |
| 2 | Dark Tech Premium | Rediseño visual de las pantallas |
| 3 | Comparador de celulares | Comparación de dos modelos y diferencia de precios |
| 4 | Panel administrativo | Búsqueda de usuarios, filtros por rol, detalles y actualización de estadísticas |

## ¿Cómo acceder a la rama de mejoras?

1. Ingresa al [repositorio en GitHub](https://github.com/RamsesAlvrz/Programacion-en-Moviles).
2. Abre el selector de ramas, donde aparece `main`.
3. Selecciona `mejora-ia-smart`.
4. Ingresa a la carpeta `Semana 12`.
5. Abre `SmartCatalog`.
6. Revisa el código y la documentación de las mejoras.

## Conclusión

La rama `main` conserva la versión base del proyecto, mientras que `mejora-ia-smart` contiene las funcionalidades adicionales implementadas con apoyo de inteligencia artificial.

Esta organización permite revisar las mejoras de manera independiente, consultar los prompts utilizados y comparar la evolución del proyecto.
